# 项目优势 — svn-git 文件版本管理

> 为什么值得用 / 为什么值得开源 · 对应版本 1.7.2

## 1. 双引擎统一：SVN 与 Git 一套界面

市面上工具要么只支持 Git（SourceTree、GitKraken、Fork），要么 SVN 工具老旧难用（TortoiseSVN 仅 Windows）。本工具**同时深度支持两种版本库**：

- 自动识别仓库类型，同样的操作（状态 / 历史 / 差异 / 分支 / 标签 / 提交 / 更新 / 还原 / 重命名）在 SVN 和 Git 下体验一致
- 适合**国内企业环境**：大量团队仍用 SVN 服务器，同时个人项目用 Git——一个工具全覆盖
- 分支 / 标签等概念差异被抽象统一（SVN 的目录复制 vs Git 的指针，界面无感知）
- Git 独有能力（Stash、推送、工作树、部分提交、修改提交注释、远程分支删除）与 SVN 独有能力（锁定、svn:ignore、cleanup、切回主干、项目迁移）各自完整，互不阉割

## 2. 并发修改防护：行业内领先的完整闭环

普通工具只告诉你「提交被拒」或「有冲突」；本工具提供**四层防护闭环**：

```
预警 → 拦截 → 解决
```

- **行级冲突检测**：提交时精确到「哪个文件第几行冲突」（而非文件级），**强制拦截**不让你提交出错版本，并给出 备份→删除→更新→手动合并 的处理指引
- **服务器更新交集提示**：服务器有新提交时，仅当**待提交文件与服务器更新文件有交集**才提示（双击即可查看差异、可先更新），无交集不打扰
- **2 分钟主动监控**：你正在修改的文件被他人先提交 → 主动弹警示条，一键查看「对方改了哪里 / 你改了哪里」双 diff 对比
- **三方冲突解决器**：基础 / 本地 / 对方三栏 + 逐文件采用 + 手动编辑，冲突处理不再靠命令行
- **合并预检**：切换 / 合并分支前自动试算——工作区改动与目标分支重叠会拦截；两边已提交改动重叠（merge-tree 三方试算）会提前预告「提交后再合并仍冲突」

对比：TortoiseSVN 冲突时给你 .mine/.r 文件自己拼；本工具把整个过程图形化了。

## 3. 局域网共享：把当前项目发给同事看

普通 SVN / Git GUI 只服务本机。本工具内置**只读共享**：

- 一个开关切换「仅本机 / 局域网 / 自定义 IP · CIDR 白名单」
- 远程默认只读：可查看历史、差异、文件，不能提交 / 编辑 / 推送
- 人数按 IP 计，避免多人重复占位；主机实时收到加入 / 离开通知
- 远程页面有门禁、满员重试、拒绝提示，顶栏显示共享 / 只读徽标
- 适合代码评审、结对排查、给同事看分支差异，不必让他们装环境或拉全量仓库

## 4. 零部署负担：一个 AppImage / 一个 exe 跑起来

- 单个 AppImage（约 97MB）内置 Node / Electron 运行时，**目标机器无需安装任何语言环境**
- Windows 提供免安装 portable exe 与 NSIS 安装包；WSL 提供 tar.gz（可内置 Node）
- 双击运行 → 弹出应用窗口（也可 `--browser` 用浏览器打开，或 `-d` 后台常驻）
- 环境自检：svn / git 缺失时提示 + 一键安装引导（免密 sudo 自动装，否则给手动命令）
- **在线更新**：AppImage / Portable / WSL 包内检查新版本、下载校验、自动换版重启，失败自动回滚

## 5. 完整的文件管理，而不只是「提交工具」

- **三种视图**：列表 / 树 / 文件浏览器图标网格（自适应列数、彩色图标、状态角标、修改数量标识）
- **多选批量操作**：矩形框选 / Ctrl 点选 / Shift 范围选，右键按**操作能力分组**一次处理整个选中集合（添加 / 提交 / 还原 / 从版本库移除 / 移到回收站 / 复制路径，各自计数，混选自动拆分）
- **拖拽上传**：文件 / 文件夹拖进窗口即上传，同名冲突可选覆盖 / 跳过 / 逐个改名；可删条目拖到窗口边缘丢弃到回收站
- **文件剪贴板**：复制 / 剪切 → 任意目录粘贴；版本化条目走 `svn move` / `git mv`
- **行数过滤**：按 `≥N` / `>N` / `<N` 筛选当前目录（含子目录），排查大代码文件
- **Markdown 预览**：渲染 + 文档目录浮层 + 8 档阅读主题；文件预览含语法高亮、图片、Blame
- **模块索引**：解析仓库内 md 的目录树或表格，把「一句话说明」注入到对应目录的文件列表
- **代码统计**：目录勾选后流式统计行数与文件数，目录小计逐级汇总，一键导出 Markdown

## 6. 发布中心：版本发布不必离开界面

- **发布历史**：GitHub Releases、各平台产物大小、源码包、下载地址
- **发布新版本**：调用项目自己的 `deploy/release.mjs`，发版脚本仍是唯一实现
- **本地打包**：AppImage / Windows / WSL 一键构建
- **旧版本清理**：保留最近 N 个版本，批量删除更早产物
- **CI 集成**：发布历史显示 GitHub Actions 构建状态、失败步骤与日志入口
- **Docker 镜像**：生成发布脚本并提供镜像大小查询

## 7. 轻量与安全

| 维度 | 说明 |
|---|---|
| 后端零框架 | 纯 Node 内置 http，无 Express / 数据库，无重型依赖 |
| 本地服务 | 默认只监听 127.0.0.1，不对外暴露；共享模式才监听网卡并过门禁 |
| 凭据安全 | 密码走 `--password-from-stdin`（ps 不可见），配置 600 权限，git 凭据 base64 存储 |
| 认证透明 | Git 推送认证失败按远程类型分场景引导（GitHub token / 服务器密码 / SSH），`GIT_ASKPASS` 自动重试 |
| 路径防护 | 全部接口防路径穿越（两侧 realpath 校验，堵 symlink 出界），CSRF / Host 校验 |
| 无注入 | 无 shell 拼接，参数全部数组传递 |
| 命令透明 | **命令预览**：悬浮任何操作项直接显示将执行的真实命令，所见即所执行 |

## 8. 现代界面体验（同类工具少有的用心）

- **16 套内置主题**（11 浅色 + 5 深色）+「我的主题」自定义 6 色；字号、界面 / 代码字体、界面与内容缩放（`Ctrl+滚轮`，`Ctrl+0` 复原）
- **操作动效**：添加盖章、删除飞出、还原擦除、提交收走、更新落座、错误抖动、后台任务光点飞行；尊重系统「减少动效」偏好
- **并排差异对比**：左原版右当前、修改行标记、滚动条绿红点全局预览、点击修改处双向跳转、语法高亮（11 种语言）；分隔栏可拖拽调宽，左右栏独立搜索
- **弹窗体验**：全部弹窗可 8 方向拖拽调整大小、右上角最大化 / 还原，Esc 关闭，点击外部不会误关
- **顶栏可定制**：工具按钮拖拽排序、拖入 / 拖出 ⋯ 菜单、插入 / 删除分隔符、恢复默认布局
- **全套彩色 SVG 图标**（不依赖系统 emoji 字体，任何 Linux 显示一致）
- 中英双语界面（2812 条 ×2），中文文件名 / 中文提交信息完整支持
- 历史视图提交总数、模糊过滤、Git 未推送绿点标记 + 右键改注释 / 撤销
- 集成终端、网络状态灯、后台任务沙漏与通知铃铛、练习仓库一键生成

## 9. 工程质量

- **约 7.1 万行 TypeScript / TSX**（strict 模式），三层架构（VCS 接口化后无 `as any`），前端按 13 个业务域拆分，依赖方向由 `check:boundaries` 机械校验
- **约 400 项自动化断言**（VCS 基础 / 扩展 / 目录还原 / 分支跟踪 / 练习仓库 / diff / 冲突解析 / HTTP API / 上传 / 竞态）+ Playwright 前端冒烟；`npm test` 一键执行，CI 自动跑
- 中英文输出兼容（系统 zh_CN.UTF-8 环境实测）
- 完整开发模式热更新（改代码即生效，免打包迭代）
- 行级冲突算法、diff 解析、冲突合并、主题派生均抽成纯函数独立单测

## 10. 为什么开源有价值

- **填补空白**：Linux 下 SVN + Git 双引擎的现代图形工具几乎没有（TortoiseSVN 是 Windows 专属，Linux 下 SVN 只能命令行）
- **企业场景刚需**：国内大量 SVN 存量项目，需要图形化工具降低使用门槛
- **架构可扩展**：VCS 抽象层清晰（22 个公共方法 + 22 个可选能力），未来可加 Mercurial / Fossil 等新引擎；平台差异下沉 `src/platform`（win32 / linux 双实现）
- **完整文档**：架构文档 + 使用教程 + 截图 + 测试脚本，新手也能维护

## 一句话总结

> **Linux / Windows 上同时把 SVN 和 Git 做到「现代图形化 + 并发防护闭环 + 局域网共享」的工具，零部署、轻量、安全、中文友好。**
